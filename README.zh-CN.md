# AI 入门路书

中文 · [English](README.md) · [Español](README.es.md) · [日本語](README.ja.md)

我做了一个小网站，给想学 AI 但不知道从哪开始的人用。

网上免费的 AI 课程很多，但刚入门时很难判断先看哪一个，而且不少课程放在 GitHub 上，打开只看到一堆文件夹。

网站会先问你几个问题：有没有工作，做什么或学什么，对什么感兴趣。然后从免费课程里给你排一条从入门到进阶的路线，并告诉你每门课先看哪里、哪些可以跳过。不确定的问题可以直接跳过。

网站免费，在浏览器里就能用，支持中文、英文、西班牙语和日语。

在线使用：https://ll-code663.github.io/ai-roadbook/
