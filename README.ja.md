# AI入門ロードブック

[中文](README.zh-CN.md) · [English](README.md) · [Español](README.es.md) · 日本語

AIを学びたいけれど、どこから始めればいいかわからない人のために、小さなWebサイトを作りました。

ネット上には無料の良いAI講座がたくさんありますが、始めたばかりだとどれから開けばいいのか判断しにくく、GitHubに置かれている講座も多いので、開いてもフォルダが並んでいるだけに見えます。

このサイトでは、まずいくつか質問をします。仕事をしているか、何の仕事や勉強をしているか、何に興味があるか。そのうえで無料講座を基礎から発展まで順番に並べ、それぞれどこから読み、どこを飛ばしてよいかを示します。答えに迷う質問はスキップできます。

無料で、ブラウザだけで使えます。日本語、英語、中国語、スペイン語に対応しています。

使ってみる：https://ll-code663.github.io/ai-roadbook/
