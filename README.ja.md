# AI入門ロードブック

**あなたのことを教えてください。最初に何を学ぶべきかをお伝えします。**

[中文](README.zh-CN.md) · [English](README.md) · [Español](README.es.md) · 日本語

👉 **今すぐ使う：https://ll-code663.github.io/ai-roadbook/**

ネット上には無料の良質なAI講座がたくさんあります。初心者がつまずくのは「見つからない」ことより、「読んでもわからない」「どこから始めればいいかわからない」ことです。良い講座の多くはGitHubに置かれていて、開くとフォルダと専門用語が並んでいるだけ、ということも少なくありません。

AI入門ロードブックは、まさにその一歩を手助けします。

## ここが違う

- **まずあなたを知ってから、おすすめする。** 仕事をしているか、どの業界か、専攻は何か、何に興味があるか。いくつかの質問に答えるだけです。珍しい専攻や職種の人は興味のある分野から選べ、どのステップにも「わからない・スキップ」があります。
- **リストではなく、ルートを。** おすすめは「スタート → 実践 → 発展」の3段階に整理し、各段階には厳選した教材だけを載せています。
- **開いたあとの読み方まで案内。** 各教材に「レッスン1〜5はコード不要、6以降は最初は飛ばしてOK」のような一言ガイドが付いています。
- **いちばん読みやすい入口へ直行。** あなたの言語の版があればそこへ直接リンクし、オンラインで読めるサイトがあればGitHubを探し回る必要はありません。
- **本当の初心者のために。** ゼロハードルモードでは、コード不要・GitHub不要の講座だけをおすすめします。専門用語はタップで解説が表示され、GitHubのはじめてガイドもあります。
- **4言語対応。** 中文・English・Español・日本語。リンクも言語に合わせた版に切り替わります。

Microsoft、Hugging Face、Google、Anthropic、Datawhale、アンドリュー・ン氏、李宏毅氏などの無料教材47件を収録しています。

## ローカルで使う

インストールは不要です。リポジトリをダウンロードし、ブラウザで `index.html` を開くだけです。

## 構成

```
index.html          ページの構造
css/style.css       スタイル
js/i18n.js          画面の文言（4言語）、用語集、専攻・職種・興味の分類
js/resources.js     教材データ（教材の追加・修正はこのファイルを編集）
js/app.js           初回の質問フロー、おすすめのロジック、各画面の描画
```
